# flatpak-trx
A build script for making a [TRX](https://github.com/LostArtefacts/TRX) flatpak.

# Dependencies:
- [flatpak](https://pkgs.org/download/flatpak)
- [flatpak-builder](https://pkgs.org/download/flatpak-builder)

# Building
```sh
./build.sh
```

# Running
```sh
flatpak run dev.lostartefacts.TRX
```
